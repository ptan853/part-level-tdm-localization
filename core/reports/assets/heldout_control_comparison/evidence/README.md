# Analysis Evidence

This snapshot accompanies the 2026-09-08 available-case report. It contains the
354 reviewer-level ratings, per-output automatic measurements (including the
four unavailable records), summary tables, paired bootstrap intervals, coverage,
and source/candidate hash-audit results. Reviewer identifiers are pseudonymous.

Differences in the bootstrap CSVs are `method_a - method_b`. The report reverses
some comparisons for consistent presentation; reversing a confidence interval
requires negating and swapping its endpoints.

The snapshot permits inspection of the numerical evidence without the large
image bundle. It does not include the images, original review-page assets, or
model weights. Re-running the complete image audit and notebook requires the
original results directory and dataset at the paths specified in the report.
Paths in the audit and input checksum records identify the original local run;
they are provenance records, not public download links.
