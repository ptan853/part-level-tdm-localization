# Data

This project will use a small selected subset of PartEdit-Bench for the first execution-focused submission.

The planned subset should contain 10-15 cases balanced by target part size. Source images and masks should stay out of git unless they are small, license-compatible examples.

Expected future contents:

- `partedit_subset/`: selected case manifest and metadata.
- `images/`: local source images, ignored by git.
- `masks/`: local ground-truth part masks, ignored by git.
