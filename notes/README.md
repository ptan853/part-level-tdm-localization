# Notes

This directory contains background material from the project formation stage.

These files are useful for context, but they are not part of the core execution pipeline:

- `harry_note.md`: original note sent to Harry.
- `reply_email.md`: email draft sent with the note.
- `related_work.md`: related-work summary.
- `experiment_plan.md`: earlier experiment plan.
- `project_plan.md`: early project plan.
- `gap_verification.md`: gap-checking notes.
- `part_level_related_work_verification.md`: related-work verification notes.
- `REPOSITORY_PLAN.md`: first repository scaffold plan.

The actual code, data manifests, configurations, results, and reports should live under `core/`.
