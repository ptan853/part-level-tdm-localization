# Final Control Comparison Design

## Goal

Make `core/reports/final_note.md` self-contained for a reader who has not read the two method-specific reports. The final comparison must explain why the control experiments were run, define both oracle-mask control operations, state the shared evaluation protocol, and support the comparison with aligned numerical and visual evidence.

## Report Structure

The existing `Control-Operation Comparison` section will be expanded in this order:

1. Background and hypothesis: accurate masks did not by themselves solve semantic part editing under the original FYS-TDM control schedule, motivating a test of the control operation.
2. Shared experimental setting: the same 12 frozen cases, seed 0, oracle GT masks, source inversion, metrics, and human rubric are used for all methods. Each operation uses one globally frozen duration rather than per-case tuning.
3. Endpoint latent projection: after a target-prompt update, the state outside the mask is projected to the time-aligned source-inversion state, while the target update is retained inside the mask.
4. Source-referenced Residual RK2: the edited trajectory is represented as a residual from the source trajectory, and the mask constraint is applied consistently at both midpoint and endpoint RK2 evaluations.
5. Quantitative and qualitative comparison, followed by a bounded conclusion.

## Visual Comparison

Generate two full-width figures containing six cases each. Every row is joined by `case_uid` and contains:

- case metadata and target prompt;
- source image;
- GT part overlay;
- Original FYS-TDM output;
- endpoint projection at the frozen global setting `N=3`;
- Residual RK2 at the frozen balanced setting `N=7`.

The figures cover all 12 cases, not only favorable examples. A short representative-case analysis will identify both improvements and persistent failures.

## Quantitative Comparison

Retain the existing common automatic and human-evaluation tables. Compare only:

- Original FYS-TDM;
- endpoint projection, `N=3`;
- Residual RK2, `N=7`.

The text must state that the two values of `N` are method-specific control durations and are not time-aligned. The result supports the effectiveness of the control operations on the frozen pilot; it does not constitute an independent-test-set proof or establish automatic localization.

## Reproducibility And Validation

The comparison figure should be generated by a reusable script with tests for all 12 case IDs, required image paths, column labels, and output files. Final validation will run the relevant unit tests, check the Markdown image targets, inspect the rendered comparison figures, and run `git diff --check`.
